# 🎙️ 小爱语音助手 (Songloft 专属扩展)


基于 Songloft 打造的智能音箱语音扩展插件。只需对小爱同学喊出自定义口令，即可全自动调用底层引擎完成播放歌单、全网搜歌、私有云寻源等操作。让你的智能音箱与私人曲库完美无缝融合，真正做到“一呼即应”！

👉 **项目主页**：[https://github.com/birdstudy-nj/songloft-lyrics-cover-helper](https://github.com/birdstudy-nj/songloft-miot-helper)

---

## 💡 核心优势

实时诊断控制台，告别语音助手的“盲人摸象”！我们打造了极其强大的实时诊断面板！

1. **它听到了什么？**：实时拦截 WebSocket，精准显示小爱音箱捕获的原始语音转文本。
2. **它触发了吗？**：意图匹配情况清晰呈现，瞬间确认触发词是否命中。
3. **它去做了什么？**：触发后的所有步骤完全透明化——平台选择、音质降级策略、云端错别字纠正、网盘寻源、临时歌单创建、推流下发……全链路每一步操作都伴随 24 小时制时间戳打印上屏，排错与调优轻松写意！

---

## ✨ 功能特性

* 🧩 **无限扩展的多引擎架构**
  彻底打破数据源壁垒。助手底层采用模块化路由分发机制，目前已完美支持 LXMusic 与 WebDAV，未来将持续接入更多优秀的音乐生态引擎，你的语音助手能力将随之不断进化。

* 🎯 **智能语音口令路由**
  * 自定义灵活映射：无论你是习惯喊“搜网易”、“放网盘”还是“听歌单”，只需自由绑定口令，引擎自动接管后续所有动作。
  * 靶向智能纠错：自带云端纠错机制，小爱听错同音字（如“五百”），系统也能自动并精准搜对歌。

* 🔔 **定制化命中与分发**
  * 命中指令后，可定制专属的智能音箱提示反馈音（内置 SongLoft_for_u 等），让交互更具确认感。
  * 支持将命中的歌曲推送到现有的指定歌单，或自动生成独立的 iWebPlayer推送 临时歌单，不弄乱你的日常曲库。
